## 🎓 **Best Practices**

### For Voice Commands:
```
✅ Clear pronunciation
✅ Quiet environment
✅ Wait for "listening" indicator
✅ Use keywords (YouTube kholo)
```

### For Quick Buttons:
```
✅ One click execution
✅ No voice needed
✅ Fast and reliable
✅ Color-coded for easy finding
```

### For Text Input:
```
✅ Exact spelling
✅ Lowercase preferred
✅ Use Enter or Send button
✅ Commands are case-insensitive
```

## 🔧 **Troubleshooting**

### Voice Not Working?
```
→ Try quick buttons instead
→ Or use text input
→ Check mic permissions
```

### Button Not Working?
```
→ Check internet connection
→ Refresh page (F5)
→ Try typing command instead
```

### Site Not Opening?
```
→ Check popup blocker
→ Allow popups for localhost
→ Try different browser
```
